# Trucksim DDK-MPC适配说明

## 修改概述

本次修改将 `inference_demo.py` 中的 Trucksim DDK 实现（使用 PyTorch Transformer 编码器）适配到 MPC 控制器中。

## 主要修改内容

### 1. ddk_controller.py

#### 1.1 添加 Transformer 编码器支持
- 从 `inference_demo.py` 复制了所有 Transformer 相关类：
  - `BatchFourierPositionalEncodingv2`
  - `TransformerEncoder` / `TransformerDecoder`
  - `TransformerEncoderLayer` / `TransformerDecoderLayer`
  - `CustomEncoderUnscaledv2`
  - `Koopmanv1`
  - 辅助函数：`_get_clones`, `_get_activation_fn`

#### 1.2 修改 DDK 类
- **支持从 .pth 文件加载 PyTorch 模型**：
  - 新增 `_load_pytorch_model()` 方法
  - 自动检测模型类型（'pytorch' 或 'matlab'）
  - 支持指定设备（'cpu' 或 'cuda'）

- **状态编码器**：
  - `encoder()` 方法支持 PyTorch 模型
  - PyTorch 模型：输入原始状态（编码器内部有 BatchNorm 归一化）
  - MATLAB 模型：输入归一化后的状态

- **状态归一化**：
  - `normalization()` 方法：对于 PyTorch 模型，只做坐标变换，不做外部归一化
  - 对于 MATLAB 模型，保持原有的归一化逻辑

- **控制输入归一化**：
  - 新增 `normalize_control()` 方法：使用 CONTROL_MIN/MAX 归一化（PyTorch 模型）
  - 新增 `denormalize_control()` 方法：反归一化控制输入
  - CONTROL_MIN/MAX 定义：
    - 转矩范围：[-1500, 1500] N·m
    - 转向角范围：[-π/2, π/2] rad

#### 1.3 更新控制维度为 12 维
- **模型参数**：
  - `state_dim = 6`
  - `control_dim = 12`（6 个转矩 + 6 个转向角）
  - `hidden_dim = 16`
  - `lift_dim = 10`
  - `space_dim = 16`

- **MPCController 默认参数**：
  - R 矩阵：12 维对角矩阵
    - 转矩权重：5（允许较大变化）
    - 转向角权重：10000（限制变化）
  - delta_umax：12 维向量
    - 转矩增量：0.5（归一化后）
    - 转向角增量：0.2（归一化后）

- **控制输入边界**：
  - PyTorch 模型：归一化范围 [0, 1]
  - MATLAB 模型：归一化范围 [-1, 1]
  - `_build_constraints()` 方法根据模型类型动态设置边界

- **控制输出转换**：
  - `convert_to_control_output()` 方法正确处理 12 维控制
  - 输出格式：[steer_LF, steer_RF, steer_LM, steer_RM, steer_LR, steer_RR,
              torque_LF, torque_RF, torque_LM, torque_RM, torque_LR, torque_RR]
  - 转向角单位：度（deg）
  - 转矩单位：N·m

### 2. ddk_mpc_sfunction.py

#### 2.1 更新控制维度
- `_controller_state['u_prev']`：从 2 维更新为 12 维
- `reset_controller()`：初始化为 12 维零向量

#### 2.2 更新 MPC 权重矩阵
- R 矩阵：12 维对角矩阵
- delta_umax：12 维向量

#### 2.3 更新控制逻辑
- 根据模型类型设置归一化范围：
  - PyTorch 模型：[0, 1]
  - MATLAB 模型：[-1, 1]

#### 2.4 更新打印输出
- 控制信息打印支持 12 维输出

### 3. mpc_main.py

#### 3.1 更新 MPC 权重矩阵
- R 矩阵：12 维对角矩阵
- delta_umax：12 维向量

## 使用说明

### 1. 模型文件格式

支持两种格式：
- **PyTorch 模型（.pth）**：从 `inference_demo.py` 训练的模型
- **MATLAB 模型（.mat/.pkl）**：传统格式（向后兼容）

### 2. 初始化 DDK 模型

```python
from ddk_controller import DDK

# PyTorch 模型
ddk = DDK('path/to/model.pth', device='cpu')  # 或 'cuda'

# MATLAB 模型（向后兼容）
ddk = DDK('path/to/model.mat')
```

### 3. 控制输入格式

**输入到 MPC 的归一化控制**：
- PyTorch 模型：范围 [0, 1]，12 维
  - 格式：[torque_LF, torque_RF, torque_LM, torque_RM, torque_LR, torque_RR,
         steer_LF, steer_RF, steer_LM, steer_RM, steer_LR, steer_RR]
- MATLAB 模型：范围 [-1, 1]，12 维

**输出到 Trucksim 的实际控制**：
- 格式：[steer_LF(deg), steer_RF(deg), steer_LM(deg), steer_RM(deg),
        steer_LR(deg), steer_RR(deg),
        torque_LF(N·m), torque_RF(N·m), torque_LM(N·m), torque_RM(N·m),
        torque_LR(N·m), torque_RR(N·m)]

### 4. 状态输入格式

**输入到编码器的状态**：
- PyTorch 模型：原始状态值（编码器内部有 BatchNorm）
- MATLAB 模型：归一化后的状态值

**状态格式**：[X(m), Y(m), Yaw(rad), vx(m/s), vy(m/s), yaw_rate(rad/s)]

## 注意事项

1. **PyTorch 依赖**：
   - 使用 .pth 格式模型需要安装 PyTorch：`pip install torch`
   - 如果未安装 PyTorch，只能使用 MATLAB 格式模型

2. **归一化范围**：
   - PyTorch 模型使用 CONTROL_MIN/MAX 归一化，范围 [0, 1]
   - MATLAB 模型使用 action_bound 归一化，范围 [-1, 1]
   - 代码会自动根据模型类型选择正确的归一化方式

3. **状态归一化**：
   - PyTorch 模型的状态归一化在编码器内部通过 BatchNorm 完成
   - 外部只需要做坐标变换（全局坐标转局部坐标）

4. **控制维度**：
   - 所有接口已更新为 12 维控制
   - 确保所有相关代码都使用 12 维
