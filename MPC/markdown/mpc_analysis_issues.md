# MPC求解分析输出问题总结

## 发现的问题

### 1. 重复打印问题 ⚠️

**现象**：
- 输出中有大量重复的 "Text report saved to..." 和 "Analysis completed!" 消息
- 控制输出信息被重复打印多次（第894-921行）

**可能原因**：
- 脚本被多次执行
- 或者有某种循环/递归调用导致重复执行

**建议**：
- 检查脚本是否被多次调用
- 确保 `main()` 函数只执行一次
- 检查是否有异常处理导致重复执行

### 2. 控制输出格式混乱 ⚠️

**现象**：
- 第900-921行出现奇怪的重复片段
- 单独的 "0.005426]" 字符串出现
- 控制输出信息被截断或重复

**可能原因**：
- 打印语句过长，被终端截断
- 或者有编码/输出缓冲问题

**建议**：
- 检查打印语句的格式
- 考虑将长字符串分行打印
- 检查终端输出设置

### 3. 控制输出数值异常 ⚠️⚠️

**现象**：
```
Steering angles: 
  LF=-83.60deg, RF=-84.09deg, LM=-82.42deg, 
  RM=-86.55deg, LR=-83.25deg, RR=-89.02deg

Torques: 
  LF=0.00N·m, RF=-1500.00N·m, LM=-0.00N·m, 
  RM=-1500.00N·m, LR=0.00N·m, RR=-1500.00N·m
```

**问题分析**：
1. **转向角异常**：
   - 所有转向角都是负值，且接近-90度（接近最小值）
   - 归一化值：u[6]~u[11] = [0.035537, 0.032819, 0.042099, 0.019184, 0.037487, 0.005426]
   - 这些归一化值很小（接近0），对应-90度左右，这是合理的
   - **但是**：初始状态是直线行驶（Yaw=0, vx=5m/s），参考轨迹也是直线（Yaw=0），为什么需要这么大的转向角？

2. **转矩异常**：
   - 左轮（LF, LM, LR）转矩为0
   - 右轮（RF, RM, RR）转矩为-1500（最大值，制动）
   - 归一化值：u[0]~u[5] = [0.5, 0.0, 0.5, 0.0, 0.5, 0.0]
   - 这会导致车辆向左转向（右轮制动，左轮无转矩）

3. **可能原因**：
   - 初始状态与参考轨迹存在偏差
   - 跟踪误差导致MPC需要大幅修正
   - 或者参考轨迹提取有问题

### 4. 跟踪误差分析 ⚠️

**从输出中看到**：
```
Tracking error:
  Error norm: 5.760317
  Max error: 1.681014
  Mean error: 0.230846
Average error by dimension: 
  x=0.854791, y=0.371193, yaw=0.017278, 
  vx=0.107248, vy=0.030347, yaw_rate=0.004222
```

**问题**：
- X方向误差较大（0.854791m）
- Y方向误差也较大（0.371193m）
- 这可能导致MPC需要大幅修正

**可能原因**：
- 初始状态（X=0, Y=0）与参考轨迹第一个点（X=0.05, Y=0）存在偏差
- 使用全局坐标后，如果参考轨迹的起点与当前状态不匹配，会导致较大的跟踪误差

### 5. A矩阵稳定性问题 ⚠️⚠️

**从输出中看到**：
```
A_ext matrix diagnostics:
  Maximum eigenvalue magnitude: 1.00301716
  Warning: A_ext matrix may be unstable!
```

**问题**：
- A矩阵的最大特征值模长 > 1.0，表示系统不稳定
- 这会导致预测误差随时间增长
- 可能影响MPC的跟踪性能

### 6. 矩阵条件数问题 ⚠️

**从输出中看到**：
```
H matrix condition number: 2.71e+04
THETA matrix condition number: 1.68e+05
PHI matrix condition number: 1.12e+22  (极大！)
```

**问题**：
- PHI矩阵条件数极大（1.12e+22），表示矩阵接近奇异
- 这会导致QP求解器收敛困难
- 虽然OSQP成功求解，但可能需要更多迭代

## 建议的修复措施

### 1. 修复重复打印问题
- 检查脚本执行流程，确保只执行一次
- 添加执行标志，防止重复调用

### 2. 修复控制输出格式
- 将长打印语句分行
- 使用更清晰的格式

### 3. 检查初始状态与参考轨迹匹配
- 确保初始状态与参考轨迹起点匹配
- 或者调整参考轨迹提取逻辑

### 4. 分析控制输出合理性
- 检查为什么需要这么大的转向角
- 验证控制输出是否符合预期

### 5. 处理A矩阵稳定性
- 考虑添加正则化
- 或者重新训练模型，确保A矩阵稳定

### 6. 处理矩阵条件数问题
- 考虑添加正则化项
- 或者调整MPC参数
