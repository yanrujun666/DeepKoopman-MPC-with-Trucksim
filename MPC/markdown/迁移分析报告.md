# Carsim到Trucksim迁移分析报告

## 一、项目架构分析

### 1.1 当前系统架构（Carsim）

**核心组件：**
- `ddk_controller.py` - DDK模型和MPC控制器核心实现
- `ddk_mpc_sfunction.py` - Python接口层，供MATLAB调用
- `matlab_function_wrapper.m` - MATLAB包装器
- `DDK_DCSUV_50ms.slx` - Simulink仿真模型（Carsim）

**数据流：**
```
Trucksim/Carsim → Simulink → MATLAB Function → Python S-Function → MPC Controller → 控制输出
```

### 1.2 关键维度定义（当前Carsim）

**状态维度 (s_dim = 6)：**
- `[X, Y, Yaw, vx, vy, yaw_rate]`
- 单位：位置(m)，角度(rad)，速度(m/s)，角速度(rad/s)
- 输入单位转换：Yaw和yaw_rate从度转换为弧度，速度从km/h转换为m/s

**控制输入维度 (u_dim = 2)：**
- `u[0]`: 转向角（归一化到[-1, 1]）
- `u[1]`: 纵向控制（归一化到[-1, 1]，正值为油门，负值为刹车）

**控制输出维度 (4维)：**
- `[steer_L1(deg), steer_R1(deg), throttle, brake]`
- 注意：Carsim使用左右转向角（steer_L1, steer_R1），通常两者相等

**DDK模型参数：**
- `state_bound`: 状态边界 `[[-0.2, -2.7, -1.2], [27.3, 1.9, 1.1]]` (3维，对应速度相关状态)
- `action_bound`: 动作边界 `[[-7.9, 0., 0.], [7.9, 0.2, 9.1]]` (3维：转向角、油门、刹车)
- `s_dim = 6`: 状态维度
- `u_dim = 2`: 控制输入维度
- `lift_dim = 10`: 提升空间维度

**参考轨迹数据格式：**
- `Pos`: 位置数据 `[X, Y, Yaw]` (N×3)
- `X`: 速度数据（已归一化）`[vx_norm, vy_norm, yaw_rate_norm]` (N×3)
- 合并后：`ref_traj = [Pos, X]` (N×6)

```python
def convert_to_control_output(self, u_normalized: np.ndarray) -> np.ndarray:
    # 转向角转换
    steer_angle = u_normalized[0] * self.ddk.a_max[0, 0] * 180 / np.pi
    steer_L1 = steer_angle
    steer_R1 = steer_L1
    
    # 纵向控制转换
    throttle = 0.0
    brake = 0.0
    if u_normalized[1] >= 0:
        throttle = u_normalized[1] * (self.ddk.a_max[0, 1] - self.ddk.a_min[0, 1]) + self.ddk.a_min[0, 1]
    else:
        brake = abs(u_normalized[1] * (self.ddk.a_max[0, 2] - self.ddk.a_min[0, 2]) + self.ddk.a_min[0, 2])
    
    return np.array([steer_L1, steer_R1, throttle, brake])
```
- **需要确认**:
  - Trucksim需要哪些控制输出？

## 六、风险评估

### 高风险项
1. **维度不匹配**：如果Trucksim的状态/控制维度与Carsim不同，需要大量修改
2. **参数文件缺失**：如果没有Trucksim的DDK模型参数，无法进行迁移
3. **接口不兼容**：如果Trucksim的S-Function接口与Carsim差异很大，需要重写接口层

### 中风险项
1. **权重矩阵调整**：可能需要重新tuning MPC权重
2. **归一化范围**：如果状态范围差异很大，可能需要调整归一化逻辑

### 低风险项
1. **路径配置**：简单的字符串替换
2. **数据格式**：如果格式相同，只需更新路径
