# MPC采样时间分析

## 一、时间步长关系

### 1.1 DeepEDMD模型的时间步长
- **模型时间步长**：`dt_model = 0.01s` (10ms)
- **A和B矩阵**：描述相邻帧为0.01s的状态变化关系
  ```
  x_{k+1} = A * x_k + B * u_k  (时间步长 = 0.01s)
  ```

### 1.2 MPC的采样时间
- **参考轨迹采样间隔**：`dt_ref = 0.01s` (10ms)
  - 从`generate_straight_acceleration_trajectory.m`和`generate_snake_trajectory.m`可以看到：`dt = 0.01`
  
- **MPC采样间隔**：`sample_interval = 5`（默认值）
  - 从`ddk_mpc_sfunction.py`：`sample_interval=5`
  - 从`mpc_main.py`：`sys_interval = 50ms`，`sample_interval = ceil(50/10) = 5`
  
- **MPC实际采样时间**：`dt_mpc = sample_interval * dt_ref = 5 * 0.01s = 0.05s` (50ms)

### 1.3 时间步长关系总结
```
模型时间步长：dt_model = 0.01s (10ms)
MPC采样时间：  dt_mpc  = 0.05s (50ms)
时间步长比例： dt_mpc / dt_model = 5
```

## 二、当前实现分析

### 2.1 MPC预测矩阵计算
在`ddk_controller.py`的`_precompute_prediction_matrices()`方法中：

```python
# PHI: 自由响应矩阵
for j in range(1, self.Np + 1):
    PHI_list.append(self.C @ np.linalg.matrix_power(self.A_ext, j))

# THETA: 强制响应矩阵
for j in range(1, self.Np + 1):
    for k in range(1, self.Nc + 1):
        if k <= j:
            row.append(self.C @ np.linalg.matrix_power(self.A_ext, j - k) @ self.B_ext)
```

**关键问题**：
- 代码直接使用`A_ext`和`B_ext`，没有考虑时间步长缩放
- `matrix_power(self.A_ext, j)`计算的是j个**模型时间步长**（0.01s）后的状态
- 但MPC的每个预测步对应的是**MPC采样时间**（0.05s）

### 2.2 时间步长不匹配的影响

**当前实现**（假设`sample_interval = 5`）：
- MPC第1步预测：使用`A^1`，实际预测0.01s后的状态（应该是0.05s）
- MPC第2步预测：使用`A^2`，实际预测0.02s后的状态（应该是0.10s）
- MPC第j步预测：使用`A^j`，实际预测`j*0.01s`后的状态（应该是`j*0.05s`）

**正确实现应该是**：
- MPC第1步预测：使用`A^5`，预测0.05s后的状态
- MPC第2步预测：使用`A^10`，预测0.10s后的状态
- MPC第j步预测：使用`A^(5*j)`，预测`j*0.05s`后的状态

## 三、正确的实现方法

### 3.1 方法1：提升A和B矩阵到MPC采样时间

如果MPC的采样时间是模型时间步长的`n`倍（`n = sample_interval`），需要将A和B矩阵提升到MPC采样时间：

```python
# 计算提升后的A和B矩阵
A_mpc = A^n  # n = sample_interval = 5
B_mpc = (A^(n-1) + A^(n-2) + ... + I) @ B
```

**对于线性系统，B矩阵的提升公式**：
```
B_mpc = sum_{i=0}^{n-1} A^i @ B
```

### 3.2 方法2：在预测矩阵计算时考虑时间步长

在`_precompute_prediction_matrices()`中，将`j`替换为`j * sample_interval`：

```python
# 修改前
PHI_list.append(self.C @ np.linalg.matrix_power(self.A_ext, j))

# 修改后
n_steps = j * sample_interval  # j个MPC步 = n_steps个模型步
PHI_list.append(self.C @ np.linalg.matrix_power(self.A_ext, n_steps))
```

## 四、代码修改建议

### 4.1 在MPCController中添加时间步长参数

```python
def __init__(self, deepedmd: DeepEDMD, Np: int = 30, Nc: int = 30, 
             Q: Optional[np.ndarray] = None, R: Optional[np.ndarray] = None,
             delta_umax: Optional[np.ndarray] = None,
             model_dt: float = 0.01,  # 模型时间步长（秒）
             mpc_dt: float = 0.05):   # MPC采样时间（秒）
    """
    Args:
        model_dt: DeepEDMD模型的时间步长（默认0.01s）
        mpc_dt: MPC的采样时间（默认0.05s）
    """
    # 计算时间步长比例
    self.time_step_ratio = int(round(mpc_dt / model_dt))  # 应该是5
    assert self.time_step_ratio > 0, "MPC采样时间必须大于等于模型时间步长"
```

### 4.2 修改预测矩阵计算

```python
def _precompute_prediction_matrices(self):
    """预计算预测矩阵PHI和THETA（考虑时间步长缩放）"""
    # PHI: 自由响应矩阵
    PHI_list = []
    for j in range(1, self.Np + 1):
        # j个MPC步 = j * time_step_ratio 个模型步
        n_steps = j * self.time_step_ratio
        PHI_list.append(self.C @ np.linalg.matrix_power(self.A_ext, n_steps))
    
    # THETA: 强制响应矩阵
    THETA_list = []
    for j in range(1, self.Np + 1):
        row = []
        for k in range(1, self.Nc + 1):
            if k <= j:
                # (j-k)个MPC步 = (j-k) * time_step_ratio 个模型步
                n_steps = (j - k) * self.time_step_ratio
                row.append(self.C @ np.linalg.matrix_power(self.A_ext, n_steps) @ self.B_ext)
            else:
                row.append(np.zeros((self.deepedmd.s_dim, self.Nu)))
        THETA_list.append(np.hstack(row))
```

## 五、当前实现的影响评估

### 5.1 预测误差
- **当前实现**：预测时间比实际时间短5倍
  - 第1步预测：0.01s（应该是0.05s）
  - 第30步预测：0.30s（应该是1.50s）
  
- **影响**：
  - MPC的预测时域实际只有预期的1/5
  - 预测精度可能下降
  - 控制性能可能受影响

### 5.2 控制性能
- **短期预测**：影响较小（前几步预测）
- **长期预测**：影响较大（后几步预测）
- **整体性能**：取决于系统动态特性
