# DDK-MPC 操作方法（Trucksim版本）

## 文件说明

**核心文件：**
- `ddk_controller.py` - DDK模型与MPC控制器实现
- `ddk_mpc_sfunction.py` - MATLAB S-Function接口
- `matlab_function_wrapper.m` - MATLAB函数包装器
- `trucksim_different_condition.slx` - Simulink仿真模型（Trucksim）

**调用关系：** Simulink → S-Function → Python控制器

## Trucksim接口说明

**状态输入（6维）：**
- `[X(m), Y(m), Yaw(rad), vx(m/s), vy(m/s), yaw_rate(rad/s)]`
- 注意：Trucksim输出已经是国际标准单位，无需转换

**控制输出（12维）：**
- `[steer_LF(deg), steer_RF(deg), steer_LM(deg), steer_RM(deg), steer_LR(deg), steer_RR(deg), torque_LF(N·m), torque_RF(N·m), torque_LM(N·m), torque_RM(N·m), torque_LR(N·m), torque_RR(N·m)]`

## 操作步骤

1. **启动Trucksim**
   - 打开Trucksim，加载车辆模型
   - 配置仿真参数

2. **连接Simulink**
   - 在Trucksim中配置S-Function
   - 打开`trucksim_different_condition.slx`模型
   - 确认S-Function已正确连接

3. **配置参数文件路径**
   - 编辑`matlab_function_wrapper.m`
   - 更新`param_path`为Trucksim DDK模型参数文件路径
   - 更新`data_path`为Trucksim参考轨迹数据文件路径
   - 注意：参考轨迹数据字段名应为`position`和`velocity`

4. **运行仿真**
   - 在Simulink中点击运行
   - 点击下方调试按钮查看输出日志

5. **查看结果**
   - 仿真一段时间后，在Trucksim中查看可视化结果

## 注意事项

- **代码更新后需重启MATLAB**，确保Simulink调用最新代码
- **DDK模型参数待定**：当前代码使用临时参数，需要等待Trucksim DDK模型训练完成后更新
- **控制维度**：当前使用临时的2维控制，待DDK模型确定后更新为12维
- **参考轨迹格式**：数据文件应包含`position`和`velocity`字段（与Carsim的`Pos`和`X`格式相同）
