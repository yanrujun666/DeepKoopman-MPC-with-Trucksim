# 控制维度降维优化说明

## 概述

实现了MPC控制维度降维功能：MPC求解时使用2维控制（转矩+转角），最终输出映射回12维控制。

## 功能特性

### 1. 兼容性设计
- **默认模式**：`use_reduced_control=False` - 使用12维控制（完整控制）
- **降维模式**：`use_reduced_control=True` - 使用2维控制（转矩+转角）

### 2. 控制映射关系

#### B_映射矩阵（12×2）
```python
B_ = [
    [1, 0],   # torque_LF -> 转矩
    [1, 0],   # torque_RF -> 转矩
    [1, 0],   # torque_LM -> 转矩
    [1, 0],   # torque_RM -> 转矩
    [1, 0],   # torque_LR -> 转矩
    [1, 0],   # torque_RR -> 转矩
    [0, 1],   # steer_LF -> 转角
    [0, 1],   # steer_RF -> 转角
    [0, 0],   # steer_LM -> 0
    [0, 0],   # steer_RM -> 0
    [0, -1],  # steer_LR -> -转角
    [0, -1]   # steer_RR -> -转角
]
```

#### 输出映射规则
- **转矩**：所有6个车轮的转矩 = 转矩值
- **转向角**：
  - 前轮（LF, RF）：= 转角
  - 中轮（LM, RM）：= 0
  - 后轮（LR, RR）：= -转角

## 修改内容

### 1. ddk_controller.py

#### MPCController.__init__
- 添加 `use_reduced_control` 参数
- 定义 `B_` 映射矩阵（12×2）
- 根据是否降维设置 `Nu`（2维或12维）
- 根据是否降维设置默认 `R` 和 `delta_umax`

#### _build_extended_model
- 如果使用降维：`B_mpc = B_full @ B_`（16×12 @ 12×2 = 16×2）
- 扩展状态空间使用降维后的控制维度

#### _build_constraints
- 根据 `Nu`（降维后的维度）构建约束矩阵
- 控制边界约束使用降维后的维度

#### solve方法
- **输入处理**：将12维 `u_prev` 映射到2维
  - 转矩：取前6维的平均值
  - 转角：从前轮转向和后轮转向（取负）中提取平均值
- **MPC求解**：使用2维控制进行优化
- **输出处理**：将2维 `delta_u` 映射回12维
  - `delta_u_12 = B_ @ delta_u_2`

### 2. ddk_mpc_sfunction.py

#### initialize_controller
- 添加 `use_reduced_control` 参数
- 根据是否降维设置 `R` 和 `delta_umax`
- 传递给 `MPCController`

### 3. mpc_main.py

#### MPCMain.__init__
- 添加 `use_reduced_control` 属性（默认False）
- 根据是否降维设置 `R` 和 `delta_umax`
- 传递给 `MPCController`

### 4. matlab_function_wrapper.m

#### 初始化部分
- 添加 `use_reduced_control` 变量（默认false）
- 传递给 `initialize_controller`

## 使用方法

### Python代码

```python
from ddk_controller import DeepEDMD, MPCController

# 加载模型
deepedmd = DeepEDMD('model.pth')

# 方式1：使用降维控制（推荐，计算更快）
mpc = MPCController(
    deepedmd,
    Np=30, Nc=30,
    use_reduced_control=True  # 启用降维控制
)

# 方式2：使用完整控制（默认）
mpc = MPCController(
    deepedmd,
    Np=30, Nc=30,
    use_reduced_control=False  # 或省略此参数
)
```

### MATLAB代码

```matlab
% 在 matlab_function_wrapper.m 中
use_reduced_control = true;  % 设置为true启用降维控制
py.ddk_mpc_sfunction.initialize_controller(param_path, data_path, 30, 30, 5, use_reduced_control);
```

## 优势

### 降维控制的优势
1. **计算效率**：MPC求解变量从 `Nc*12` 降到 `Nc*2`，大幅减少计算量
2. **数值稳定性**：更小的优化问题，条件数更好
3. **求解速度**：QP求解器处理更小的Hessian矩阵，速度更快

### 完整控制的优势
1. **灵活性**：可以独立控制每个车轮
2. **精确性**：不受降维映射约束限制

## 注意事项

1. **控制映射**：
   - 降维模式下，所有转矩必须相等
   - 转向角必须满足：前轮=转角，中轮=0，后轮=-转角
   - 如果实际控制不满足这些约束，降维映射会有误差

2. **权重矩阵**：
   - 降维模式：`R` 应该是2维对角矩阵 `[转矩权重, 转向角权重]`
   - 完整模式：`R` 应该是12维对角矩阵

3. **控制增量约束**：
   - 降维模式：`delta_umax` 应该是2维 `[转矩增量, 转向角增量]`
   - 完整模式：`delta_umax` 应该是12维

4. **输出格式**：
   - 无论使用哪种模式，最终输出都是12维
   - `convert_to_control_output` 方法保持不变

## 技术细节

### B矩阵降维
```python
# 原始B矩阵：16×12
B_full = deepedmd.B  # (16, 12)

# 降维后的B矩阵：16×2
B_mpc = B_full @ B_  # (16, 12) @ (12, 2) = (16, 2)
```

### 控制映射
```python
# 2维控制 -> 12维控制
u_12 = B_ @ u_2  # (12, 2) @ (2,) = (12,)

# 12维控制 -> 2维控制（最小二乘投影）
u_2 = (B_^T @ B_)^(-1) @ B_^T @ u_12
```

### 实际实现
- 从12维到2维：使用直接提取方法（转矩取平均，转角从前/后轮提取）
- 从2维到12维：使用B_矩阵映射
